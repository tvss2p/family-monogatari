# ファミリー物語（スマホ用パチンコゲーム）設計書

2026-10-29 ／ だいすけ と Claude で決めた内容

## 1. なにを作るか・なぜ

だいすけの家族（だいすけ・ひろこ・ななえ）と猫たちのイラストを使った、スマホで遊ぶパチンコゲーム「ファミリー物語」。
海物語のような「液晶で図柄がまわり、3つそろうと大当たり、奇数は確変」というわかりやすいルールで、
**豪華で大迫力な実機風の筐体**と、**モニターの外で動くギミック**が見どころ。
いちばんの当たりは「家族3人が肩を組んだ絵」がそろうこと（「家族揃って大当たり！」）。

成功のイメージ：スマホのホーム画面から開いて、本物のパチンコ台を打っている気分で、家族や猫が出てくる演出を楽しめる。

## 2. 目標・やらないこと・失敗とみなすこと

**目標**
- スマホたて画面で、本物らしく玉が釘に当たって落ち、ヘソに入ると液晶がまわる
- ChatGPTのイメージ図2（`gpt/concept2.png`）の豪華さに近い見た目
- 液晶の外の可動ギミックが場面ごとに大きく動く
- GitHub Pages で公開し、ホーム画面に追加するとアプリのように動く（PWA）
- 玉は無料で借りられる

**やらないこと（今回は）**
- 本物のお金・課金・ランキング・オンライン機能
- 右打ち・ST・複数の台・横画面のレイアウト
- 海物語そのもののキャラ・演出名（魚群・マリンちゃん等）のまね。仕組み（図柄・確変・時短・保留・リーチ）だけ借りる

**失敗とみなすこと（動いていても）**
- 盤面が飾りで埋まって、玉の通り道が見えない（だいすけが2回目の絵で直した点）
- ギミックや演出が、液晶の図柄・文字・家族の顔を隠す
- 玉がすぐなくなって楽しめない／当たらなさすぎる
- iPhoneで重い・カクつく

## 3. 決まっていること

### 3-1. 見た目
- 方向性：ChatGPTのイメージ図2。パールピンク×ゴールド、虹色のLED、ピンクと水色の宝石。絵柄は渡されたイラストと同じ水彩＋色鉛筆、こげ茶の線
- 台の名前：「ファミリー物語」（「だいすけ家」は入れない）
- 台のてっぺん：ねこ耳の王冠＋ハートの宝石＋ロゴ、左右に金の羽、データカウンター（回転・大当り・確変）
- 液晶の上の役物：**なーふぁん**（白ねこ）のフィギュア、小さな王冠つき
- ヘソ（玉が入ると液晶がまわる穴）の飾り：**家族3人**の絵
- 液晶は大きく中央。液晶の中のデザイン（丸いシール風の図柄＋番号バッジ、たてにまわるリール）はデザイン案1〜3のものを使う
- 盤面は白っぽい透明なガラスの板。金の釘と銀の玉がはっきり見える。左に玉が上がる金のレール
- 手前：上皿（玉・まん中に大きなPUSHボタン・もち玉表示・玉貸/返却）、下皿、右下に銀のハンドル、左右のスピーカー
- 大当たりの文字：「家族揃って大当たり！」

### 3-2. 作り方（だいすけが A を選んだ）
- **筐体のわく**と**動くギミックの部品**は、ChatGPT に描いてもらう。頼むのは Claude（だいすけの Chrome の ChatGPT を操作してよい、とだいすけが許可済み）
- 絵のOKを待つあいだも、盤面・物理・液晶・ゲームの仕組みは仮の部品（デザイン案3のもの）で先に作り、OKが出たら絵を差しかえる（Claude の判断）
  - 筐体のわくは、盤面と液晶の場所を空けた絵（あとでプログラムで抜くか、はじめから透明にしてもらう）
  - 部品は1つずつ背景なし：金の羽（左右）、なーふぁんのフィギュア、肉球アーム、家族3人のヘソ飾り、ねこじゃらし、風車、PUSHボタン、ねこ耳の王冠＋ロゴ
  - 参考に渡してよいもの：だいすけが送ったイラスト12枚、筐体の見本のスクショ、イメージ図2
  - 絵柄がそろわない部品は描きなおしてもらう。組み立てた見た目は、だいすけに見せてOKをもらってから先へ進む
- **盤面（釘・玉・レール・ヘソ・アタッカー）と液晶**はプログラムで描く
- 玉は本当に物理で動かす（重力・釘との衝突・はね返り）

### 3-3. 図柄とルール（デザイン案1でだいすけが「おおよそOK」）
図柄は12種類。番号つき11種＋特別な★。

| 番号 | 図柄 | 種類 |
|---|---|---|
| 1 | ジル | 確変 |
| 2 | リー | 通常 |
| 3 | ベリー | 確変 |
| 4 | なーふぁん | 通常 |
| 5 | ラッキー | 確変 |
| 6 | キラ | 通常 |
| 7 | グレン | 確変 |
| 8 | だいすけ | 通常 |
| 9 | ひろこ | 確変 |
| 10 | ななえ | 通常 |
| 11 | ハニー | 確変 |
| ★ | 家族3人（肩を組んだ絵） | プレミアム |

- 3つそろうと大当たり。奇数＝確変、偶数＝通常、★＝プレミアム
- 当たりやすさ：ふだん約1/99（あまめ）
- 確変：次の大当たりまで約1/10
- 通常の大当たりのあと：時短100回（当たりやすさは1/99のまま、玉がへりにくい）
- 大当たり：10ラウンド。★（3人そろい）は16ラウンド＋確変＋特別ムービー
- 保留は4つまで
- 玉は無料：「玉貸」でいつでも、何度でも借りられる

### 3-4. 演出とギミック（デザイン案3で動きを見てもらったもの）
液晶の中：
- 図柄がたてにまわる → 左・右の順に止まる → 2つそろうとリーチ → まん中がゆっくり
- 予告：肉球ペタペタ予告、ハニー横切り予告、**にゃんこ大行進**（猫たちが画面を横切る。出たらアツい）
- リーチ：ノーマルリーチ、**家族リーチ**（家族3人が出てくる。激アツ）
- 激アツ：「ボタンを押せ！」
- 3人そろい：家族3人の大きな絵＋「家族揃って大当たり！」＋紙吹雪

液晶の外のギミック（10種）：
1. ねこ耳クラウン：激アツで耳がピクピク、大当たりでパタパタ。ハートが回り、ロゴに光が走る
2. なーふぁん落下役物：激アツで液晶のまん中に落ちてきて光る
3. 肉球アーム：リーチで左右から出てきて、ヘソのよこでねこパンチ（液晶の図柄は隠さない）
4. 家族ヘソ：大当たりでせり上がって金色に光る
5. PUSHボタン：激アツで上皿から飛び出し、まわりのLEDが回る
6. 金の羽：ふだんは台のうしろ。激アツでバサバサ、大当たりで台の外まで大きくひらく
7. ねこじゃらし：盤面の右上。ふだんはゆらゆら、リーチで速く
8. 台ごとブルブル：激アツと大当たりの瞬間に台全体がふるえる
9. 全面カットイン：激アツの瞬間に「激アツ！！」の帯が台の前を横切る
10. LED・スピーカー・風車：場面ごとに光の速さと色が変わる。大当たりは金色の点滅・白いフラッシュ・後光

### 3-5. 遊ぶ環境
- スマホのたて画面向け（iPhone が中心）
- GitHub に置き、GitHub Pages で遊べるようにする
  - アカウント：tvss2p（だいすけの Chrome でログイン中。ほかのゲーム「たって、こじか」なども公開リポジトリ）
  - リポジトリ名：family-monogatari（公開）。遊ぶURLは https://tvss2p.github.io/family-monogatari/ になる。PWA の start_url とサービスワーカーの範囲はこのパスに合わせる
  - ページはだれでも見られる（GitHub Pages の仕様）。リポジトリにはゲームで使う大きさの画像だけを入れ、`assets/original` の元画像は入れない（Claude の判断）
  - このMacには gh コマンドがないので、push の方法は計画で決める（Chrome の GitHub から作る、など）
- ホーム画面に追加するとアプリとして動く（PWA：manifest とサービスワーカー、オフラインでも開ける）

## 4. Claude が決めたこと（だいすけはまだ確認していない）

- **玉の出入り**：はじめのもち玉250。玉貸1回で125玉。ヘソに入ると3玉もどる。アタッカーは1ラウンド10玉まで、1玉につき15玉もどる（10Rで約1500玉、16Rで約2400玉）
- **打ち方**：右下のハンドルを指でさわっている間、玉が自動で出る（1秒に約1.6玉）。ハンドルを回す角度で強さが変わり、玉の落ちる場所が変わる
- **当たりの決め方**：玉がヘソに入った瞬間に抽選して保留にためる（本物と同じ順番）。図柄の止まり方・リーチ・予告は抽選の結果から決める
- **★の出やすさ**：大当たりのうち約1割を★（3人そろい）にする
- **音**：効果音は入れる（合成音）。BGM は後で。音のオン・オフのボタンをつける
- **振動**：Android は振動もつける。iPhone のブラウザは振動できないので、画面のブルブルだけ
- **保存**：もち玉・回転数・大当たり回数などを端末に保存し、次に開いたとき続きから
- **横向き**：「たてにしてね」と出す
- **液晶にかぶる演出のきまり**：なーふぁん落下と全面カットインは、激アツのあいだ「まん中の図柄がまだまわっている間」だけ液晶にかぶってよい（デザイン案3でだいすけが見た動き）。止まった図柄・リーチや大当たりの文字・家族の顔にはかぶせない。まん中が止まる前に、なーふぁんは上にもどり、カットインは抜けきる
- **画面の大きさ**：たて 390×844 を基準に、画面に合わせて全体を拡大・縮小する。切り欠き（ノッチ）とホームバーの分は内側に寄せる

## 5. 作り方の候補（比べたもの）

| 案 | 中身 | よいところ | 弱いところ |
|---|---|---|---|
| **A（決定）** | 筐体とギミック部品は ChatGPT の絵、盤面と液晶はプログラム | 絵の豪華さと、ギミックが本当に動くことの両方 | 部品を10枚ほど頼む。絵柄のずれは描きなおしで合わせる |
| B | イメージ図1枚を背景にして、玉と液晶を重ねる | いちばん早い | ギミックが動かない。絵の釘に玉を合わせるのがむずかしい |
| C | 全部プログラムで描く（デザイン案3の延長） | 軽い・直しやすい | ChatGPT の絵ほど豪華にならない |

だいすけが A を選んだ理由：イメージ図2の豪華さが好きで、動くギミックも欲しいから。

## 6. 作る人に任せること
- 物理の細かい数値（釘の配置、はね返り、玉の速さ）。ただし「ヘソに入る割合」と「1回転あたりの玉の減り方」が遊びやすくなるよう調整する
- 予告・リーチの出る割合と当たりやすさ（「にゃんこ大行進」「家族リーチ」は出たらアツいと感じられること）
- 使う技術（Canvas か DOM か、ライブラリの有無）。iPhone で 60fps を目指す
- ChatGPT への頼み方の文面と、部品の切り抜き方
